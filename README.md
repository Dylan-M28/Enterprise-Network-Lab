# Enterprise-Network-Lab
Hands-on enterprise network design, implementation, security, and troubleshooting lab.

## Status
In Progress

## Objective

Design, implement, secure, and troubleshoot a simulated ~100-user enterprise network using Cisco networking concepts and Packet Tracer.

## Technologies

- Cisco Packet Tracer
- VLANs
- 802.1Q trunking
- STP/RSTP
- Inter-VLAN routing
- OSPF
- DHCP/DNS
- NAT/PAT
- ACLs
- SSH
- Wireshark
- Network troubleshooting

## Architecture

The lab uses a two-tier collapsed-core architecture consisting of:

- 1 WAN edge router
- 2 multilayer collapsed-core switches
- 2 Layer 2 access switches
- Segmented user, server, guest, and management networks
